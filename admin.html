Google Calendar

Connectez votre Google Calendar pour que les réservations et dates bloquées y apparaissent automatiquement.

Comment obtenir un Client ID :

  1. Allez sur Google Cloud Console et créez un projet
  2. Allez dans API Library et activez Google Calendar API
  3. Allez dans OAuth consent screen, choisissez "External", remplissez le nom et email
  4. Allez dans Credentials → Create Credentials → OAuth client ID
  5. Type: Web application
  6. Ajoutez votre URL de site dans Authorized JavaScript origins (ex: https://votre-user.github.io)
  7. Copiez le Client ID et collez-le ci-dessous
